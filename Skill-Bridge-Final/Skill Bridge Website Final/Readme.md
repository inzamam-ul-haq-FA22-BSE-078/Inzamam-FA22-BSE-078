# 🚀 Skill Bridge

> A MERN Stack based collaborative skill-sharing and project collaboration platform that enables users to exchange skills, communicate in real-time, and work together on projects efficiently.

---

# 📌 Project Overview

**Skill Bridge** is a modern web application developed as a Final Year Project (FYP).  
The platform is designed to provide:

- 🤝 Peer-to-peer skill exchange
- 💬 Real-time communication
- 📂 Project collaboration
- 🏆 Skill verification system
- 🔔 Dashboard management
- 🔍 Advanced skill search and filtering

The application is developed using the **MERN Stack** along with **Socket.io** for real-time features.

---

# 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| React.js | Frontend Development |
| Node.js | Backend Runtime |
| Express.js | REST APIs |
| MongoDB | Database |
| Socket.io | Real-Time Communication |
| JWT | Authentication & Security |
| CSS | Styling & UI |

# ⚙️ Prerequisites

Before running the project, make sure the following software is installed on your system:

- ✅ Node.js
- ✅ npm (Node Package Manager)
- ✅ MongoDB Compass
- ✅ Visual Studio Code

---

# 📥 Installation & Setup Guide

## 1️⃣ Download the Project

Download or clone the complete project folder from GitHub.

```bash
git clone https://github.com/your-username/your-repository-name.git
```

Or manually download the ZIP folder and extract it.

---

# 🗄️ MongoDB Setup

## 2️⃣ Install MongoDB Compass

Download and install **MongoDB Compass**.

Make sure MongoDB services are running properly before starting the backend server.

---

# 💻 Open Project in VS Code

## 3️⃣ Open the Project Folder

Open the complete **Skill Bridge Final** folder inside **Visual Studio Code**.

---

# 🔧 Backend Setup

## 4️⃣ Open Backend Terminal

Open a new terminal in VS Code and run:

```bash
cd backend
```

---

## 5️⃣ Install Backend Dependencies

```bash
npm install
```

---

## 6️⃣ Start Backend Server

```bash
node server.js
```

✅ Backend server will start successfully.

---

# 🎨 Frontend Setup

## 7️⃣ Open Second Terminal

Open another terminal in VS Code and run:

```bash
cd frontend
```

---

## 8️⃣ Install Frontend Dependencies

```bash
npm install
```

---

## 9️⃣ Start Frontend Application

```bash
npm start
```

✅ Frontend application will start successfully.

---

# 🌐 Run the Application

After starting both frontend and backend servers, the application will automatically open in your default browser.

If it does not open automatically, manually open:

```bash
http://localhost:3000
```
